# Interpretable Multimodal Physiological State Estimation Layer (`lamina::autonomic`)

The `lamina::autonomic` module provides an interpretable, transparent, and mathematically grounded physiological state estimation engine for Lamina. It consumes windowed `MultimodalFeatureVector` outputs generated by Task 7 and transforms them into structured evidence representations, physiological activation and regulation indices, multi-tiered confidence metrics, and state trajectory series.

---

## 1. Non-Clinical Guardrails & Scientific Rationale

> [!IMPORTANT]
> **Non-Clinical & Non-Diagnostic Boundary**:
> The Lamina autonomic estimator provides an interpretable multimodal physiological state representation. It does **not** directly measure sympathetic or parasympathetic neural outflow, does **not** establish a "sympathovagal balance" ratio ($X/Y$), and is **not** clinically validated for medical decision support or diagnostic classification.

### Scientific Guardrail Summary
- **No Direct Sympathetic/Parasympathetic Output**: HRV metrics (`RMSSD`, `SDNN`, `pNN50`) are treated strictly as **cardiac variability evidence**.
- **RespHRV Terminology & Context**: Respiratory heart rate variability (RespHRV / RSA) amplitude is evaluated strictly in the context of direct respiratory measurements and is **not** presented as a context-free "vagal tone index."
- **Electrodermal Arousal**: EDA metrics are described as **electrodermal activation evidence**, not total sympathetic nervous system output.
- **Baseline-Relative Interpretation**: Physiological features are normalized relative to individual baseline distributions rather than arbitrary global population cutoffs.

## 4. Observed Features vs. Derived State Hierarchy

Lamina enforces a clean separation between raw DSP features and derived state representations:

```text
Raw Signal Waveforms (ECG, PPG, EDA, RSP)
        ↓
Modality DSP & Peak Detection (Tasks 1–5)
        ↓
Multimodal Coupling (Task 6)
        ↓
Windowed Feature Vectors [MultimodalFeatureVector] (Task 7)
        ↓
Baseline Normalization & Quality Gating [AutonomicBaseline]
        ↓
Interpretable Physiological State Representation [AutonomicState]
        ↓
Evidence Confidence & Temporal Trajectory [AutonomicStateSeries]
```

## 5. Mathematical Formulations

### 5.1 Baseline Normalization
For feature value $x$, standard z-score normalization is defined as:
$$z = \frac{x - \mu}{\sigma + \epsilon}$$

Robust Median / MAD normalization is defined as:
$$z = \frac{x - \text{median}}{c \cdot \text{MAD} + \epsilon}$$
where $c = 1.4826$ provides normal-equivalent scaling and $\epsilon = 10^{-6}$ regularizes zero-variance baselines.

### 5.2 Directional Orientation & Bounded Transform
Directional orientation applies feature direction ($d \in \{+1, -1\}$):
$$z_{\text{directed}} = d \cdot z$$

Hyperbolic tangent scaling bounds normalized values strictly into $[-1.0, 1.0]$:
$$\text{score} = \tanh\left(\frac{z_{\text{directed}}}{s}\right)$$
where $s > 0$ (`bounded_scale`, default $2.0$).

### 5.3 Multimodal Composite Weighted Score
For $M$ valid, quality-gated contributing features with normalized values $x_i$ and weights $w_i > 0$:
$$\text{Composite Score} = \frac{\sum_{i=1}^M w_i x_i}{\sum_{i=1}^M w_i} \quad \in [-1.0, 1.0]$$
If $\sum w_i = 0$, the composite score yields `None`.

### 5.4 First-Order Exponential Moving Average (EMA) State Smoothing
For sequential state series trajectory with smoothing factor $\alpha \in (0.0, 1.0]$:
$$s_t = \alpha x_t + (1 - \alpha) s_{t-1}$$
Raw, unsmoothed window evaluations remain accessible in un-smoothed estimators.

## 6. Derived State Indices & Representations

### 6.1 `CardiacState`
- `variability_index`: Normalized SDNN/RMSSD evidence in $[-1.0, 1.0]$.
- `heart_rate_index`: Normalized mean HR evidence in $[-1.0, 1.0]$.
- `recovery_evidence`: Bounded composite cardiac recovery evidence index in $[-1.0, 1.0]$.
- `beat_count`: Observed ECG R-peaks in window.

### 6.2 `ElectrodermalState`
- `tonic_level_index`: Bounded Tonic SCL index in $[-1.0, 1.0]$.
- `phasic_activation_index`: Bounded Phasic SCR activation index in $[-1.0, 1.0]$.
- `scr_rate_index`: Bounded SCR event rate index in $[-1.0, 1.0]$.
- `scr_count`: Observed SCR events in window.

### 6.3 `RespiratoryState`
- `rate_index`: Bounded Respiratory Rate evidence index in $[-1.0, 1.0]$.
- `amplitude_index`: Bounded breath cycle amplitude index in $[-1.0, 1.0]$.
- `regularity_index`: Bounded cycle regularity index in $[-1.0, 1.0]$.
- `cycle_count`: Observed breath cycles in window.

### 6.4 `CouplingState`
- `resphr_coupling_index`: Bounded RespHRV (RSA) coupling evidence index in $[-1.0, 1.0]$ (conditioned on valid respiration).
- `phase_coupling_index`: Bounded cardiorespiratory phase concentration index in $[-1.0, 1.0]$.
- `pulse_delay_index`: Bounded ECG-PPG pulse delay index in $[-1.0, 1.0]$.
- `association_count`: Observed SCR cardiorespiratory associations.

### 6.5 `AutonomicState` Composite Scores
- **Physiological Activation Evidence Index (`activation_score`)**: Bounded composite index ($[-1.0, 1.0]$) aggregating HR, EDA phasic, SCR rate, and respiratory rate evidence.
- **Cardiorespiratory Regulation & Coupling Index (`regulation_score`)**: Bounded composite index ($[-1.0, 1.0]$) aggregating cardiac variability, RespHRV, and phase concentration.

## 7. Multi-Tiered Evidence Confidence (`StateConfidence`)

Modality confidences ($[0.0, 1.0]$) measure data completeness, temporal coverage, quality flags, and event counts:
- `cardiac`: Evaluates temporal coverage, beat count ($\ge 10$), and `cardiac_valid` flag.
- `electrodermal`: Evaluates temporal coverage and `eda_valid` flag.
- `respiratory`: Evaluates temporal coverage, cycle count ($\ge 4$), and `respiration_valid` flag.
- `coupling`: Evaluates coupling validity and respiratory context availability.
- `overall`: Unweighted mean across present modality confidences.

---

## 8. Missing Modality Semantics & Quality Gating

1. **No Artificial Zeros**: Missing modalities produce `None` and do not inject $0.0$ or population defaults.
2. **Quality Gating**: Features with temporal coverage below `min_coverage` (default $0.70$) or failed quality flags are excluded prior to normalization and weighted composite aggregation.
3. **Graceful Confidence Reduction**: Partial modality inputs (e.g., ECG-only or ECG+EDA) yield valid derived indices for available signals while overall confidence decreases appropriately.

## 9. Algorithmic Complexity

State estimation is performed strictly over Task 7 feature vectors without rescanning raw recording timelines:

| Operation | Complexity | Description |
| :--- | :---: | :--- |
| Baseline fitting (`AutonomicBaseline::fit`) | $O(W_b \times F)$ | Computes mean/std/median/MAD over $W_b$ baseline windows |
| Single window estimation (`estimate`) | $O(F)$ | Normalizes $F$ features and computes weighted composites |
| Trajectory estimation (`estimate_series`) | $O(W \times F)$ | Sequential estimation over $W$ windows |
| EMA Trajectory smoothing | $O(W)$ | First-order EMA pass across $W$ window states |
